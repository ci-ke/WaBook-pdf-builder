# WaBook-pdf-builder

WaBook / mdBook 结构 markdown 图书的一键 PDF 构建工具。
读取图书仓库(含 `SUMMARY.md`),生成排版完整的中文 PDF:**不改动图书仓库任何文件**,PDF 输出到自定目录。

适用于任何以 `SUMMARY.md` 组织章节的图书,例如《Go语言圣经》([gopl-zh](https://github.com/gopl-zh/gopl-zh.github.com))。

## 依赖

| 依赖 | 说明 |
|---|---|
| **pandoc 3.x** | 从 [pandoc.org](https://pandoc.org) 下载便携版解压即可;可用环境变量 `PANDOC` 指定可执行文件路径 |
| **XeLaTeX** | 推荐 MiKTeX;编译中缺失宏包时自动下载安装(`--enable-installer`,不改任何配置) |
| **系统中文字体** | 正文 Cambria、中文 SimSun、代码 Consolas(Windows 自带) |

## 用法

```bash
python build.py <图书根目录> [PDF输出目录]
```

示例:

```bash
# 输出到当前目录
python build.py D:\books\my-book

# 输出到指定目录
python build.py D:\books\my-book D:\out

# 详细模式(打印聚合进度、完整 pandoc 命令与内部过程)
python build.py --verbose D:\books\my-book D:\out
```

产物: `<PDF输出目录>/book.pdf`(可用环境变量 `PDF_NAME` 改名)

`PANDOC` 环境变量示例(便携版):

```bash
export PANDOC="D:\Software\pandoc\pandoc.exe"
python build.py D:\books\my-book D:\out
```

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PANDOC` | `pandoc` | pandoc 可执行文件路径(PATH 中可直接调用时无需设置) |
| `PDF_NAME` | `book.pdf` | 输出 PDF 文件名 |

## PDF 特性

- 结构:封面(第一个文件 `index.md`,标题转粗体)→ 目录 → 后续章节
- 每个大章节(章级条目)从新页开始
- 章/节自动编号;Contents 页与 PDF 阅读器书签编号一致
- 代码块浅灰底、语法高亮;正文 12pt、1.25 倍行距、2.5cm 边距
- 源文件中手写的 "3.4." 等节号前缀自动剥离,避免与自动编号重复;三级小标题转为粗体段落
- 目录链接跳转保持阅读器当前缩放(符合 PDF 常规行为)

## 输入协议(构建器如何解读图书仓库)

构建器只以**图书根目录**为输入,读取以下文件:

| 文件 | 角色 | 解析规则 |
|---|---|---|
| `SUMMARY.md` | 章节清单与层级(**必读**) | 缩进层级 → 章/节/前置文档,见下 |
| `index.md` | 封面(约定):标题转粗体段落,**不占编号、不进目录/书签**;其余内容原样作为封面页 | 若书无此文件,则无封面页(需自行调整) |
| 各章节 `*.md` | 正文 | 见"章节文件规则" |
| `images/` 等目录 | 图片资源 | 相对路径引用,由 pandoc `--resource-path` 指回图书目录解析 |

**SUMMARY.md 解析规则**

| 行形态 | 归类 | 处理 |
|---|---|---|
| 顶层、无 `*` 前缀,如 `[译者序](preface-zh.md)` | **前置文档** | 不参与编号;出现在目录;内部所有标题转粗体(不进目录);如译者序/前言 |
| 顶层 `*` 开头,如 `* [第 1 章](ch1/ch1.md)` | **章** | 自动编号;章前强制分页(新页开始) |
| 缩进两空格的 `*`,如 `  * [1.1](ch1/ch1-01.md)` | **节** | 自动编号,编号格式 `章.节` |

**章节文件规则**(每个 `.md` 的通用处理)

1. **首个 H1/H2 标题** → 转为章/节标题(层级取自 SUMMARY),标题文本剥离手写编号前缀(正则:数字点分如 `3.4. `、中文如 `第 3 章 `),使自动编号唯一
2. 文件内其余 `##` 标题 → 保留,自动编号(作为节内小标题)
3. `###` 及更深标题 → 转为**粗体段落**:不进目录、不编号(假设目录只有两级)
4. 前置文档(译者序/前言)内**所有**标题都转粗体
5. 图片相对路径 `../images/x.png` → `images/x.png`(聚合文档在临时目录,由 `--resource-path` 定位)
6. 文本清洗:字面 `\r\n` → 行内代码(防止 LaTeX 误解析为控制序列);含 `^` 的 `$...$` → `\(...\)` 数学分隔符(保留仅有的 3 处数学公式,同时避免裸 `$` 破坏排版)

**LaTeX 定制(`header.tex`)**:目录结束后强制另起一页;代码块浅灰底 `shadecolor`;PDF 阅读器书签带编号(`bookmarksnumbered`)。

## 通用化依据:当前硬编码假设清单

做通用化调整时,只需核对以下假设是否满足目标书;全部假设都是"无该特征则自动跳过"或"改一处即可":

| # | 假设 | 代码位置 | 若不满足 |
|---|---|---|---|
| 1 | 存在 `index.md` 作为封面 | `build.py` 中 `file == "index.md"` | 无此文件则全书无封面;改名需改此处 |
| 2 | 无 `*` 顶层条目 = 前置文档(不编号) | `isTop` 判定 | 无前置文档的书自然跳过 |
| 3 | 目录只需两级(章/节) | `cleanInnerHeadings` 三级转粗体 | 需要三级目录时改为保留 `###` |
| 4 | 标题带手写编号前缀(`3.4. `、`第 3 章 `) | 两处前缀剥离正则 | 无前缀的书原样保留(no-op) |
| 5 | 正文出现裸 `$`(shell 提示符/金额),几乎没有数学公式 | `-f markdown-tex_math_dollars` | 含大量 LaTeX 数学的书需去掉该开关 |
| 6 | 中文排版(宋体/雅黑系) | 字体 `-V` 参数 | 西文书改 `mainfont`/`CJKmainfont` |
| 7 | 输出文件名固定 | `PDF_NAME` 环境变量(默认 `book.pdf`) | 直接改环境变量即可 |

## 内部结构

| 文件 | 作用 |
|---|---|
| `build.py` | 聚合章节 + 调用 pandoc 编译(单入口,Python 3 + 类型注解) |
| `header.tex` | LaTeX 定制:目录后另起一页、代码块灰底、书签编号 |

中间文件在系统临时目录,编译后自动清理;不在图书目录留下任何文件。

## 注意

- 重新生成的 PDF 会覆盖输出目录中的同名文件
- 若图书结构变化(新增/删除章节),`SUMMARY.md` 会自动反映到新 PDF 中
